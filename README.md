📸 Photography Website

A simple and elegant photography portfolio website built using HTML and CSS.
This project showcases a collection of photography work in a clean and responsive layout.

🌟 Overview

This website was created as a personal photography portfolio to highlight beautiful moments captured through the lens. It presents selected images along with a short introduction about the photographer and their journey.

The design focuses on:

Simplicity

Clean layout

Easy navigation

Responsive structure

🛠️ Built With

HTML5

CSS3

No frameworks or external libraries were used — making it lightweight and beginner-friendly.

🚀 Getting Started

To run this project locally:

Clone the repository:

git clone https://github.com/RobbinK-code/Photography-website.git


Navigate into the project folder:

cd Photography-website


Open index.html in your browser.

That’s it! 🎉

🎨 Customization

You can easily personalize this website by:

Replacing the images with your own photography.

Editing the text content in index.html.

Updating styles in styles1.css to match your brand colors and layout preferences.
